# CrossBridge AI · 产品原型设计与 UI 视觉方案（V1.0）

> 对应《项目开发方案书》第二阶段"MVP 开发"的第一步交付物：产品原型设计 + UI 视觉方案。
> 配套可视产物：`prototype/` 静态视觉原型（HTML 设计稿，含三个页面，可直接在浏览器查看效果）。
>
> **升级说明（V1.1）**：静态原型已升级为可运行 Demo，页面迁至 `frontend/`（零构建 HTML+CSS+JS），
> 接入后端分析接口并支持离线降级；设计规范不变，本文件继续作为视觉标准。页面截图见 `docs/screenshots/`。

---

## 0. 设计目标与原则

| 原则 | 说明 |
|---|---|
| **比赛现场可用** | 3 分钟讲清价值；三页结构一屏一卖点；演示剧本一键填充 |
| **国际商务 AI 质感** | 参考企业级 SaaS（Notion/Linear/OpenAI 系）：克制用色、大留白、卡片化、细节精致；**避免学生作业风**（不要花哨渐变、不要五颜六色、不要大段堆字） |
| **离线零依赖** | 不引用 Google Fonts / CDN 图标库，全部系统字体 + 内联 SVG，比赛现场断网也能完整展示 |
| **专业而非玩具** | 报告页是"体检报告"的质感：评分环、雷达图、问题对照卡，信息密度高但有秩序 |

## 2. 用户操作流程

### 流程 A：演示剧本路径（比赛主推，约 90 秒）
```
首页 → 点击"示例文本"按钮（邮件/谈判/会议任选）
     → 文本自动填入 + 场景自动选中
     → 点击[开始检测]
     → 六步分析动画（场景识别→语言→礼仪→文化→评分→生成报告，约 4–6 秒）
     → 进入报告页，评委目光随讲解逐区移动
```

### 流程 B：自由输入路径（演示"真实可用"）
```
首页 → 手动输入一段文本（中英均可）→ 选择场景 → [开始检测] → 报告页
```

### 流程 C：案例库探索（演示"专业内核"）
```
导航 → 案例库 → 切换分类筛选 → 查看案例（原表达/风险/优化/文化解释）
     → （可选）点击案例卡片"代入检测"→ 该案例原文填入首页并触发分析
```

### 报告页内交互
- 五维评分条 hover 显示评分依据一句话；
- 每个问题卡片可展开"优化表达 + 文化解释"；
- [复制优化表达] 按钮（演示"可直接使用"）；
- [重新检测] 返回首页。

## 3. 视觉设计规范

### 3.1 色彩方案（企业级蓝 + 风险色系）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主品牌色 | `#1D4ED8`（蓝） | 主按钮、链接、强调 |
| 主品牌深色 | `#1E3A8A`（深藏蓝） | 报告头部横幅渐变、Logo、页脚 |
| 浅品牌色 | `#EFF4FF` / `#DBEAFE` | 卡片底色、标签底色、选中态 |
| 页面底色 | `#F6F8FB`（极浅灰蓝） | 页面背景 |
| 卡片/面板 | `#FFFFFF` | 卡片、输入区 |
| 主文字 | `#0F172A`（深墨） | 标题、正文 |
| 次级文字 | `#475569` | 说明文字 |
| 弱化文字 | `#94A3B8` | 占位符、辅助信息 |
| 描边 | `#E2E8F0` | 卡片边框、分隔线 |
| **风险-低** | `#16A34A` 绿 | Low Risk · 低风险 |
| **风险-中低** | `#D97706` 琥珀 | Medium-Low · 中低风险 |
| **风险-中高** | `#EA580C` 橙 | Medium-High · 中高风险 |
| **风险-高** | `#DC2626` 红 | High Risk · 高风险 |
| 五维-语言 | `#2563EB` | Language Accuracy |
| 五维-礼貌 | `#7C3AED` 紫 | Business Politeness |
| 五维-文化 | `#0EA5E9` 青 | Cultural Adaptability |
| 五维-清晰 | `#F59E0B` 金 | Communication Clarity |
| 五维-友好 | `#10B981` 绿 | Relationship Friendliness |

**用色纪律**：页面 90% 为中性色（白/灰/深墨），彩色只出现在"风险等级、五维评分、按钮、Logo 强调"四处——彩色越少，专业感越强。

### 3.2 字体与排版

| 项目 | 方案 |
|---|---|
| 中文 | `PingFang SC` / `Microsoft YaHei`（系统字体，离线可用） |
| 英文/数字 | `Inter` / `Segoe UI` / 系统 sans-serif（数字用 `tabular-nums` 对齐） |
| Logo 字体 | 无衬线加粗 + 字母间距 `0.04em`，"AI" 二字用主色 |
| 页面大标题 | 28–34px / 700 |
| 区块标题 | 18–20px / 600 |
| 卡片标题 | 15–16px / 600 |
| 正文 | 14–15px / 400，行高 1.7 |
| 辅助标签 | 12px / 500，字母间距 `0.06em`（英文小标签大写） |

### 3.3 间距 · 圆角 · 阴影（统一设计令牌）

| 令牌 | 值 | 说明 |
|---|---|---|
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 | 页面留白充足（大留白=高级感） |
| 圆角 | 小 8px（标签/按钮）、中 12px（卡片）、大 16px（主卡片/输入区） | 圆角克制，不超 16px |
| 阴影 | 卡片：`0 1px 2px rgba(15,23,42,.04), 0 4px 12px rgba(15,23,42,.05)`；悬浮：阴影加深 + `translateY(-2px)` | 轻投影，不花哨 |
| 内容宽度 | 主内容区最大 `1100px`，居中 | 演示屏 1280–1920 均舒适 |

### 3.4 Logo 设计（内联 SVG）

```
CrossBridge AI
┌─────────────────────────────┐
│        ╭───╮                │
│     ╭──╯   ╰──╮             │  ← 拱桥形（横跨一条"鸿沟"）
│  ───╯         ╰───          │  ← 桥面与两端桥墩
└─────────────────────────────┘
```

- **图形**：两座桥墩 + 拱桥，桥下留一道缝隙——寓意"跨越文化鸿沟（bridge the gap）"。
- **配色**：桥身渐变 `#1D4ED8 → #0EA5E9`，缝隙透出背景色。
- **文字**："CrossBridge" 深墨 700，"AI" 主蓝色。
- 导航/页脚统一使用同一 SVG 组件。

### 3.5 组件规范

| 组件 | 规格 |
|---|---|
| **主按钮 [开始检测]** | 高 44px，圆角 10px，主蓝底白字，右箭头图标；hover 加深 `#1E40AF`；loading 态转圈 |
| **场景选择器** | 胶囊按钮组：默认白底灰字灰边；选中态浅蓝底 + 主蓝字 + 主蓝边；5 个等宽胶囊 |
| **风险徽章** | 小圆角标签：底色 = 风险色 10% 透明度，文字 = 风险色 600；含小圆点状态指示 |
| **评分环** | SVG donut：半径 52px，进度弧线渐变蓝，中心大字总分 + "满分100" 小字 |
| **雷达图** | SVG 五轴多边形：网格 4 层（10/20/30 档），数据多边形半透明蓝填充 + 蓝边，五轴顶点标签 |
| **维度评分条** | 横向进度条（圆角 4px）：底色浅灰，填充色=该维度专属色；右侧分数 `90/100` |
| **问题卡片** | 白卡 + 左边框色条（按问题类型：语言蓝/礼仪紫/文化青）；含"原句引用"（等宽/引用样式）、分析文字、类型标签、严重度 |
| **优化对照卡** | 双栏：左"原文"（灰底、删除线语义的红点标注）→ 右"优化表达"（浅绿底 + 绿色文字）；下方"文化解释"块（浅蓝底 + 💡 图标） |
| **案例卡** | 网格卡：顶部（场景标签 + 风险徽章），中部原表达（引用样式），底部推荐表达（绿）+ 文化解释（弱化文字） |
| **导航** | 吸顶白底细描边；左 Logo，右链接（当前页高亮主蓝字 + 下划线指示） |

## 4. 功能模块 → 页面/组件映射

| 方案书模块 | 页面 | 组件/区域 |
|---|---|---|
| 模块1 文本输入 | 首页 | 文本域 + 场景选择器 + 示例填充 + 开始检测 |
| 模块2 场景识别 | 首页→报告 | 场景胶囊选中态；报告头部显示识别结果（场景标签） |
| 模块3 跨文化风险分析 | 报告页 | 风险分析区：问题卡片（类型标签：语言/礼仪/文化） |
| 模块4 评分模型 | 报告页 | 评分环 + 雷达图 + 五维评分条 + 风险徽章 |
| 模块5 优化建议 | 报告页 | 优化对照卡（原文→优化→文化解释） |
| 模块6 案例数据库 | 案例库页（联动报告页） | 分类筛选 + 案例卡网格；报告页底部"相关案例" |

## 5. 数据展示方式

- **综合分**：评分环（直观、可截图传播）；
- **五维**：雷达图（记忆点）+ 评分条（精确数值）；
- **问题**：卡片列表，每条=原句引用+分析+类型标签+严重度；
- **优化**：双栏对照（左灰右绿），强化"给你可直接用的答案"；
- **文化解释**：独立浅蓝解释块（💡），突出"翻译软件给不了的部分"；
- **案例**：卡片网格 + 分类筛选，突出"专业积累"。

## 6. 交互细节与演示适配

| 项 | 方案 |
|---|---|
| 分析动画 | 六步状态条（场景识别→语言分析→礼仪分析→文化分析→五维评分→生成报告），每步打勾推进，总时长 4–6 秒；演示时评委"看着 AI 在工作" |
| 演示剧本 | 首页三个示例按钮（邮件催款 / 谈判压价 / 会议发言），一键填入文本+场景 |
| 复制功能 | 优化表达卡片提供"复制"按钮（演示可直接使用） |
| 响应式 | 优先 1280px+ 桌面演示；窄屏自动降级为单列，手机可访问 |
| 离线 | 全部系统字体 + 内联 SVG，无任何外部资源请求 |
| 品牌细节 | 页脚注明"AI + 商务英语 + 跨文化交际"，强化新文科属性 |
