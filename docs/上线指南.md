# CrossBridge AI · GitHub 一键上线手册（完整版）

> 前提：您已有 GitHub 账号。本手册只需 3 大步、约 10 分钟。
> 待部署内容已备好：`deploy/github-repo/`（含 Dockerfile，容器平台自动识别）。

============================================================
第 1 步：把 github-repo 内容推送到 GitHub
============================================================
1. 打开 https://github.com/new 新建公开仓库，名称建议：
   `crossbridge-ai-demo`
2. 两种上传方式任选：

   方式①（网页拖拽，最简单）：
   - 新建仓库后进入仓库页面 → Add file → Upload files
   - 把 `deploy/github-repo/` 里的内容（Dockerfile、backend、
     frontend、data、README.md、.dockerignore）全部拖进去
   - Commit changes

   方式②（Git 命令，需已装 Git）：
   ```
   cd D:\DSH\CrossBridge-AI\deploy\github-repo
   git init
   git add .
   git commit -m "CrossBridge AI Demo v1.0"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/crossbridge-ai-demo.git
   git push -u origin main
   ```

============================================================
第 2 步：选一个平台部署（二选一，都免费、GitHub 登录）
============================================================

—— 方案 A：Hugging Face Spaces（推荐，国内访问更顺畅）——
1. 打开 https://huggingface.co → 点 Sign in → 选 "Sign in with GitHub"
   （自动用 GitHub 账号创建 HF 账号，无需注册新账号）
2. 右上角 New Space → 配置：
   - Space name：`crossbridge-ai-demo`
   - SDK：Docker
   - Hardware：CPU basic（免费）
   - 创建后进入 Settings → 连接 GitHub 仓库，或直接点
     "Import from GitHub" 关联刚建的仓库
3. 等待自动构建（Builds 标签看进度，约 2–5 分钟）
4. 完成后访问（可发给任何人，无需本地环境）：
   `https://<你的用户名>-crossbridge-ai-demo.hf.space`

—— 方案 B：Render（全程 GitHub，免费）——
1. 打开 https://render.com → Sign up → 用 GitHub 登录
2. Dashboard → New → Web Service → 连接刚建的 GitHub 仓库
3. 部署设置：
   - Runtime：Docker（检测到根目录 Dockerfile 自动选择）
   - Instance Type：Free
   - 直接 Deploy，等待构建（约 3–5 分钟）
4. 完成后访问：`https://crossbridge-ai-demo.onrender.com`
   （免费实例空闲会休眠，首次打开等约 30 秒属正常）

============================================================
第 3 步：验证与分享
============================================================
1. 打开线上地址，确认：
   - 首页正常显示（无"离线演示模式"黄条 = 后端在线）
   - 输入任意文本 → 开始检测 → 报告页实时生成
2. 把线上链接发给老师/同学/评委即可体验。
3.（可选）启用真实大模型增强：
   - 在平台环境变量中添加 `DEEPSEEK_API_KEY=sk-xxx`
   - 不配置也不影响（内置规则引擎自动工作）

============================================================
常见问题
============================================================
- 页面出现"离线演示模式"横幅 → 说明后端没起来：查看构建日志
- 构建失败 → 确认 Dockerfile 上传到了仓库根目录（不是子文件夹）
- 国内访问 Render 慢 → 优先用方案 A（HF Spaces）
- 想换网址名 → 平台里改 Space/Service 名称即可
