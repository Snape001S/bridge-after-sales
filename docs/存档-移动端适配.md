## 二、适配内容要点

1. **全局防溢出兜底**：`html, body { overflow-x: hidden }`；图片/SVG/雷达图 `max-width:100%` 等比缩放（不变形）。
2. **≤768px**：导航品牌与链接分行（链接可横滑）；报告头部/评分区纵向排列居中；应用价值纵向对比；模型页六层单列。
3. **≤480px**（覆盖 375/390/414）：场景中心单列；CTA 按钮全宽；输入区/推理行/问题卡纵向排列；雷达图上限 280px；按钮 44px 触屏高度；长文本自动换行。
