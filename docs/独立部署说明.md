# 独立部署说明

本目录是桥通售后的独立副本，原 CrossBridge AI 项目不受影响。

## Render
1. 将 `BridgeAfterSales` 目录上传到一个新的 GitHub 仓库，例如 `bridge-after-sales`。
2. Render → New → Blueprint，选择该仓库。
3. 确认服务名为 `bridge-after-sales-demo`，健康检查 `/api/health`。
4. 如需启用大模型，在 Render 环境变量中配置 `DEEPSEEK_API_KEY`；不配置时使用规则引擎兜底。
5. 部署完成后，Render 会分配一个新的 `onrender.com` 地址。

## 本地检查
使用 Python 运行 `backend/main.py` 或 Docker 启动服务，访问 `/api/health`。
