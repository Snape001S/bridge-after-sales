# CrossBridge AI · Render Docker 部署指南

> 适用：包含后端服务的完整版部署（本项目为 FastAPI 后端 + 前端，**非纯静态**，
> 前端由后端托管，`/api/*` 接口由后端提供，离线降级仅用于无后端浏览场景）。
> 仓库已含 `Dockerfile` 与 `render.yaml`，两种部署方式任选。

---

## 方式一：Blueprint 蓝图一键部署（推荐，最省事）

1. 登录 [render.com](https://render.com)（**Continue with GitHub** 授权即可）
2. Dashboard → **New** → **Blueprint**
3. 选择仓库 `Snape001S/CrossBridge-AI`
4. Render 自动读取根目录的 `render.yaml`，创建服务 `crossbridge-ai-demo`
   （runtime: docker → 自动用 Dockerfile 构建）
5. 点 **Apply** → 等待构建（首次约 3–6 分钟）
6. 完成后访问：`https://crossbridge-ai-demo.onrender.com`

## 方式二：手动创建 Web Service

1. Render 控制台 → **New** → **Web Service**
2. **Connect a repository** → 选 `Snape001S/CrossBridge-AI`
3. 配置：
   | 字段 | 值 |
   |---|---|
   | Name | `crossbridge-ai-demo` |
   | Runtime | **Docker**（自动识别根目录 Dockerfile） |
   | Instance Type | **Free** |
   | Health Check Path | `/api/health` |
4. 点 **Create Web Service** → 等待构建 → 打开 `https://crossbridge-ai-demo.onrender.com`

## 环境变量（可选增强）

| 变量 | 说明 |
|---|---|
| `DEEPSEEK_API_KEY` | 启用真实大模型分析（效果更强）。在 Render 控制台 → Environment 中添加；不配置则使用内置规则引擎（免费离线，功能完整） |
| `AI_PROVIDER` | 手动指定通道：`deepseek` / `siliconflow` / `ollama` / `mock`（默认 auto） |

## 常见问题

| 问题 | 处理 |
|---|---|
| 构建失败 | 查看 Events 日志；确认 Dockerfile 在仓库根目录（不在子目录） |
| 页面显示"离线演示模式" | 后端未启动成功：检查 `/api/health` 与构建日志 |
| 打开很慢 | 免费实例休眠唤醒，等待即可；或考虑付费实例 |
| 需要自定义域名 | Render 控制台 → Settings → Custom Domain |
