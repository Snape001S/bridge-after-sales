# CrossBridge AI · Render 部署说明（含架构速览）

## 一、架构速览（部署前必读）

```
用户浏览器 ──HTTP──> FastAPI 后端（backend/main.py，端口 ${PORT}）
                        │  托管前端（frontend/ 静态页面，同源）
                        ├── /api/analyze        实时风险分析（推理/评分/三策略）
                        ├── /api/cases          案例库
                        ├── /api/diagnosis      沟通诊断画像
                        ├── /api/comparisons    前后对比
                        └── /api/scene-cases    场景案例
                        │
                        └── data/*.json         只读知识库（无数据库）
```

- **技术栈**：Python · FastAPI · Uvicorn · Pydantic；前端零构建原生 HTML/CSS/JS。
- **无数据库**：4 个 JSON 知识库只读加载；用户输入/报告/账号均不持久化（内存计算 + 浏览器 sessionStorage 临时会话）。
- **API 地址**：前端 `api.js` 中 `API_BASE = ""`（同源相对路径，由后端托管页面，无需跨域配置）。

## 二、部署方式一：Blueprint 一键（推荐）

1. 登录 https://render.com → **Continue with GitHub** 授权
2. Dashboard → **New** → **Blueprint** → 选仓库 `Snape001S/CrossBridge-AI`
3. Render 读取根目录 `render.yaml`，自动创建 Web Service `crossbridge-ai-demo`（runtime: docker）
4. 点 **Apply** → 等构建（约 3–6 分钟）
5. 访问 `https://crossbridge-ai-demo.onrender.com`

## 三、部署方式二：手动创建 Web Service

1. **New** → **Web Service** → **Connect a repository** → 选 `CrossBridge-AI`
2. 字段配置：

   | 字段 | 值 |
   |---|---|
   | Name | `crossbridge-ai-demo` |
   | Runtime | **Docker**（自动使用根目录 Dockerfile） |
   | Instance Type | **Free** |
   | Health Check Path | `/api/health`（可选） |

3. Build Command / Start Command：**留空**（Dockerfile 已内置：`pip install -r backend/requirements.txt` + `uvicorn main:app --host 0.0.0.0 --port ${PORT:-7860}`）
4. **Create Web Service** → 等待构建 → 打开网址

> 若平台不支持 Docker 而只能选 Python runtime，则手动填：
> - Build Command：`pip install -r backend/requirements.txt`
> - Start Command：`uvicorn main:app --host 0.0.0.0 --port $PORT`
> - Root Directory：`backend`

## 四、Environment Variables

| 变量 | 必填 | 说明 |
|---|---|---|
| `PORT` | 否（Render 自动注入） | 服务端口 |
| `DEEPSEEK_API_KEY` | 否 | 可选：启用真实大模型分析（效果更强）；不配置则用内置规则引擎（免费离线，功能完整） |
| `AI_PROVIDER` | 否 | 可选：`auto`（默认）/ `deepseek` / `siliconflow` / `ollama` / `mock` |
| `SILICONFLOW_API_KEY` / `OLLAMA_BASE_URL` | 否 | 其他大模型通道 |

配置位置：Render 控制台 → 服务 → **Environment** → Add Environment Variable。

**验证 Key 是否生效**：部署后打开 `https://xxx.onrender.com/api/health`，
查看 `ai_provider` 字段——`"deepseek"` 表示增强模式生效；`"mock"` 表示未配置/未识别（规则引擎回退，功能完整）。

## 五、部署后验证清单

| 检查 | 方法 | 预期 |
|---|---|---|
| 服务在线 | 打开 `/api/health` | `{"status":"ok",...}` |
| 首页 | 打开根路径 | 无黄色"离线演示模式"横幅 |
| 实时分析 | 输入文本 → 开始检测 | 出报告（评分/推理/三策略/相关案例） |
| 数据接口 | 打开 `/api/cases` | 30 条案例 |

## 六、免费版注意事项与常见问题

- 免费实例闲置 **15 分钟休眠**，首次访问等待约 30–60 秒——**演示前提前打开预热**。
- 构建失败 → Events 日志；确认 Dockerfile 在仓库**根目录**。
- 页面出现"离线演示模式"横幅 → 后端未成功启动，检查 `/api/health` 与构建日志。
- 需要自定义域名 → 服务 Settings → Custom Domain。
